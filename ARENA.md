# ARENA — Pon a 100 Claudes a pelear por tu respuesta
*Recurso del video sobre Arena — Brian Anderson / CashFunnel*

- Repo (licencia MIT): https://github.com/Jakeschincariol/arena-skill
- Qué hace: skill para Claude Code que convierte una pregunta en un torneo de subagentes y se queda con la mejor respuesta.
- Gratis, sin registro ni API key. Necesita Claude Code y Python 3.8+.
- Instalar: copia la carpeta del skill a tus skills de Claude Code (o instálalo como plugin: `/arena-skill:arena`). Ver README.
- Ojo: lanza subagentes por oleadas (10 por defecto), así que gasta bastante uso de tu plan. Resérvalo para decisiones importantes.
