# COMBO: Claude Code de 20 dólares más Codex de 20, frente al Ultra de 200

Recurso del video sobre el combo Claude Code + Codex. Brian Anderson / CashFunnel, noviembre de 2026.

**COMBO no es un plugin ni un producto con ese nombre.** Es una forma de partir el trabajo entre dos planes de unos 20 USD al mes: **Claude Pro**, que incluye [Claude Code](https://claude.com/pricing?mode=code), y **ChatGPT Plus**, que incluye [Codex](https://openai.com/codex/), frente al **Claude Ultra** de 200 USD al mes.

El objetivo es usar cada herramienta en lo que rinde, no clonar el volumen del Ultra. El combo **no equivale** al Ultra en uso, y el ahorro no es un número fijo.

## Cómo partir el trabajo

1. **Codex (Plus)** para el volumen: refactors repetidos, tests, boilerplate, PRs mecánicos.
2. **Claude Code (Pro)** para lo difícil: arquitectura, revisión y decisiones que no quieres a medias.
3. Cuando se acabe el cupo de uno, no subas a Ultra por inercia: primero cambia de herramienta o de un modelo más barato.

En Claude Code también puedes instalar el plugin de Codex (documentación: https://code.claude.com/docs/en/plugins) si quieres tener las dos herramientas en el mismo flujo.

## Límites honestos
