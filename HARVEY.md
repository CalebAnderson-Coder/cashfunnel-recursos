# HARVEY — Agente de ventas gratis en Claude Code
*Recurso del video sobre Harvey — Brian Anderson / CashFunnel*

- Repo (gratis, open source): https://github.com/ethanplusai/harvey
- Qué hace: busca negocios a los que venderles, aprende algo específico de cada uno, escribe un correo en frío que lo menciona, lo envía, lee las respuestas y lleva la conversación hacia una reunión. Corre en tu computadora, en bucle.
- Requisito: usa tu suscripción **Claude Pro o Max** vía Claude Code (o ChatGPT vía Codex). Sin API key ni cobro por token. El plan gratis de Claude no alcanza.

## Guía rápida
1. Instala Claude Code y clona el repo; sigue el README.
2. Define tu cliente ideal (industria, cargo, país).
3. Empieza con **10 prospectos** y **revisa cada correo antes de enviarlo**.
4. Usa un dominio/correo secundario para envíos en frío y respeta las leyes anti-spam.
