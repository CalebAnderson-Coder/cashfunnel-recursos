# OPEN — Open Design: diseña webs, paneles y presentaciones con tu agente
*Recurso del video sobre Open Design — Brian Anderson / CashFunnel*

- Repo (Apache-2.0, código abierto): https://github.com/nexu-io/open-design · Guía rápida: https://github.com/nexu-io/open-design/blob/main/QUICKSTART.md
- Qué hace: un espacio de diseño de escritorio que usa el agente que ya tienes (Claude Code, Codex, Cursor, Gemini, OpenCode…) o tu propia clave (OpenAI, Anthropic, o local con Ollama) para crear webs, landing pages, prototipos, dashboards, presentaciones, imágenes y video.
- Exporta: HTML, PDF, PowerPoint (PPTX editable), ZIP y MP4 (videos con HyperFrames).
- Con tu marca: le das una captura o URL y crea un `DESIGN.md` reutilizable.

## Ojo (lo honesto)
Código abierto **no** significa que el modelo sea gratis: pagas el agente/clave que conectes, o usas un modelo local. El servicio alojado (OpenDesign Cloud) tiene planes de pago. Las imágenes del video son ejemplos del proyecto.

## Primer uso
1. Instala la app de escritorio siguiendo QUICKSTART.
2. Conecta tu agente o clave.
3. Elige plantilla (landing, deck, dashboard) + sistema de diseño, escribe el brief y revisa la vista previa.
4. Pasa el HTML a tu agente de código para seguir construyendo, o exporta.
