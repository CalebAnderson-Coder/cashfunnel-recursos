# SETUP — Everything Claude Code (ECC), el setup que ganó el hackathon de Anthropic
*Recurso del video sobre ECC — Brian Anderson / CashFunnel*

- Repo (open source): https://github.com/affaan-m/ECC
- Qué trae: ~314 skills, 71 agentes y 98 comandos que convierten Claude Code en un equipo de desarrollo (revisión de seguridad, memoria limpia, aprendizaje entre sesiones). Nativo en Codex; Cursor y Gemini con adaptadores.
- Su autor ganó el hackathon Anthropic x Forum Ventures (sep 2025) con este setup.

## Cómo empezar sin romper nada
1. Lee el README del repo.
2. **No instales todo de una.** Empieza solo con los agentes de revisión de seguridad/código.
3. Pasa cada skill por SkillSpector antes de instalar (ver recurso SEGURO).
4. Agrega más piezas cuando sepas qué hace cada una.
