# SYS — mapa del sistema (Claude + Systeme)
*Recurso del video sobre Claude + Systeme.io — Brian Anderson / CashFunnel*

Checklist para montar un sistema de captura → seguimiento → entrega/pago. **Es una plantilla de arquitectura**, no un sistema ya instalado ni una garantía de ventas.

## Qué hace cada pieza
- **Claude**: borradores de oferta, textos de ventas, correos, descripción de producto/curso y mensaje a afiliados. Tú revisas antes de publicar.
- **Systeme.io**: formularios, etiquetas, secuencias de correo, páginas, pagos, entrega de curso y afiliados (según tu plan).

## Checklist (márcalo tú)
- [ ] **Oferta**: qué entregas, para quién, y qué NO incluye
- [ ] **Contenido**: borrador en Claude → revisión humana → versión final
- [ ] **Captura**: formulario + consentimiento + página de gracias
- [ ] **Clasificación**: etiquetas con criterios verificables (clics, interés, etapa)
- [ ] **Seguimiento**: secuencia con salida clara y revisión periódica
- [ ] **Entrega/pago**: procesador real; límites del plan y comisiones confirmadas en la web oficial
- [ ] **Afiliados** (si aplica): reglas, comisión y material revisado

## Empezar en Systeme
1. Crea cuenta en https://systeme.io (condiciones y precios oficiales: https://systeme.io/pricing).
2. Monta el embudo mínimo: captura → secuencia → oferta.
3. Pega el contenido revisado de Claude (no publiques el primer borrador a ciegas).
4. Prueba el flujo completo con un correo tuyo antes de abrirlo.

## Límites reales (léelos)
- «Empezar gratis» = **plan free publicado por Systeme**, no significa APIs ilimitadas, ni cero comisiones, ni resultados garantizados. Revisa precios y límites vigentes en https://systeme.io/pricing.
- Claude consume tu plan de Anthropic (o el que uses). No inventes métricas de conversión.
- Los gráficos del video son **demostración**, no capturas de transacciones reales.

## Prompt corto para Claude (punto de partida)
```
Ayúdame a preparar el primer borrador de un negocio digital en Systeme:
1) oferta clara (qué / para quién / qué no incluye),
2) texto de ventas corto,
3) secuencia de 5 correos con objetivo por correo,
4) descripción del producto/curso,
5) mensaje para afiliados.
Sé concreto. Marca supuestos. No inventes resultados ni pruebas sociales.
```
