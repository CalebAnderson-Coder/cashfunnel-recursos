# WEB — 4 piezas para diseñar una web con un agente
*Recurso del video "Cuatro piezas para diseñar una web" — Brian Anderson / CashFunnel*

1. **Código: Claude Code** — el agente que construye. https://docs.anthropic.com/en/docs/claude-code/overview
2. **Animaciones: Motion (antes Framer Motion)** — `npm install motion`. https://motion.dev
3. **Reglas de diseño: UI UX Pro Max Skill** — estilos, paletas, tipografías y reglas UX para el agente. https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
   ```bash
   npm install -g ui-ux-pro-max-cli
   cd tu-proyecto && uipro init --ai claude
   ```
   (requiere Python 3)
4. **Componentes: 21st.dev** — biblioteca de componentes de interfaz listos para copiar. https://21st.dev

## Cómo combinarlas
Pide a Claude Code la web con UI UX Pro Max activo → agrega componentes de 21st.dev → anima con Motion → revisa en el navegador (móvil y escritorio) antes de entregar.
No hay precio ni ahorro de tiempo garantizado: revisa siempre el resultado. Para más herramientas de diseño, mira el recurso **DISEÑO**.
